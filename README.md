# สแกนเอกสาร OCR ภาษาไทย (app-scan)

เว็บแอปสำหรับมือถือ ใช้กล้องโทรศัพท์สแกนเอกสารได้ทั้ง **ถ่ายรูป** และ **วิดีโอ**
อ่านข้อความภาษาไทยด้วย **OpenThai2.0-OCR-Text ของ iApp** (สำรองด้วย Tesseract) แล้วบันทึกเป็นไฟล์ **Word (.docx)**

- ไม่ต้องติดตั้งจาก App Store / Play Store — เปิดผ่านเบราว์เซอร์ แล้วกด “เพิ่มไปยังหน้าจอหลัก” ใช้งานเหมือนแอป
- **ประมวลผลในเครื่องทั้งหมด** ภาพและข้อความไม่ถูกส่งขึ้นอินเทอร์เน็ต (เหมาะกับเอกสารบัญชี/ภาษีที่เป็นความลับ)
- ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## ความสามารถ

| โหมด | การทำงาน |
|---|---|
| 📷 ถ่ายรูป | ถ่ายทีละหน้า ใช้ความละเอียดสูงสุดของกล้อง (Android) อ่านข้อความต่อเนื่องอัตโนมัติ ถ่ายหน้าต่อไปได้ทันที |
| 🎥 วิดีโอ | กดอัดแล้วเลื่อนกล้องผ่านเอกสารทีละหน้า ระบบเลือก **เฟรมที่คมชัดที่สุด** ทุก 1–5 วินาที และ **ตัดเฟรมซ้ำ/ไม่มีข้อความ** ให้อัตโนมัติ ดาวน์โหลดไฟล์วิดีโอเก็บไว้ได้ |
| 🖼 นำเข้าไฟล์ | เลือกรูปหลายรูปจากเครื่อง หรือไฟล์วิดีโอ (ดึงเฟรมให้อัตโนมัติ) |

- **Thai OCR แบบออฟไลน์ 2 ตัว** (ดูหัวข้อ [เครื่องมือ OCR](#เครื่องมือ-ocr))
  - **OpenThai2.0-OCR-Text** ของ iApp (ค่าเริ่มต้น) — โมเดลขนาดเล็ก ~4 MB รันในเบราว์เซอร์ด้วย onnxruntime-web
    ตรวจภาพตะแคง/กลับหัวแล้วหมุนให้ตั้งตรงอัตโนมัติ แยกคอลัมน์ในแถวเดียวกันด้วย tab
  - **Tesseract** — ตัวสำรองเมื่อเบราว์เซอร์รุ่นเก่ารัน OpenThai ไม่ได้ (สลับให้อัตโนมัติ) พร้อมปรับพื้นกระดาษที่มีเงาให้ขาวเท่ากันก่อนอ่าน
- **แก้ข้อความไทยอัตโนมัติ**: `จํากัด → จำกัด`, `เเบบ → แบบ`, ลำดับวรรณยุกต์, ช่องว่างผิดที่, `1, 050 . 00 → 1,050.00`
  และเลือกแปลงเลขไทยเป็นเลขอารบิกได้
- **แก้ไขแต่ละหน้า**: หมุน, ครอป, แบ่งภาพหนังสือกางเป็น 2 หน้า, อ่านใหม่, แก้ข้อความ, จัดลำดับหน้า, ลบหน้า
- **โหมดหนังสือ**: รวมบรรทัดเป็นย่อหน้า แยกหัวข้อจากตัวอักษรที่ใหญ่กว่า ตัดเลขหน้าและหัวกระดาษ
  แบ่งภาพหนังสือกาง 2 หน้าเป็นซ้าย/ขวาอัตโนมัติ (ดู [โหมดหนังสือ](#โหมดหนังสือ))
- **PDF เหมือนต้นฉบับ**: ภาพหน้าจริง + ชั้นข้อความล่องหนวางตรงตำแหน่งบรรทัด ค้นหา/คัดลอกข้อความภาษาไทยได้
- **ไฟล์ Word**: A4, ฟอนต์ TH Sarabun New 16 pt (เปลี่ยนได้), แนบภาพสแกนเหนือข้อความ,
  ขึ้นหน้าใหม่ทุกหน้า, มีเลขหน้า — ตั้งฟอนต์แบบ complex script (`w:cs`) ให้ภาษาไทยแสดงถูกต้องใน Word
- ส่งออก `.txt`, คัดลอกข้อความทั้งหมด, แชร์ไฟล์ Word/PDF ไป LINE/อีเมล/Drive (มือถือที่รองรับ)
- งานที่สแกนเก็บไว้ในเครื่อง (IndexedDB) ปิดแอปแล้วเปิดใหม่ข้อมูลยังอยู่

## เปิดใช้งานบนมือถือ (GitHub Pages)

กล้องบนมือถือใช้ได้เฉพาะเว็บที่เป็น **HTTPS** จึงแนะนำให้เผยแพร่ผ่าน GitHub Pages (ฟรี):

1. ที่ repository บน GitHub ไปที่ **Settings → Pages**
2. ช่อง **Source** เลือก **GitHub Actions**
3. Merge โค้ดเข้า branch `main` — workflow `Deploy to GitHub Pages` จะ build และเผยแพร่ให้อัตโนมัติ
4. เปิด `https://ykk2sxs-tech.github.io/app-scan/` บนมือถือ แล้วกด **อนุญาต** ให้ใช้กล้อง
5. (แนะนำ) เพิ่มไปยังหน้าจอหลัก
   - Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
6. (ถ้าจะใช้แบบออฟไลน์) ไปที่ **ตั้งค่า → เตรียม OCR สำหรับใช้งานออฟไลน์** หนึ่งครั้งตอนมีอินเทอร์เน็ต

> หมายเหตุ: GitHub Pages ของ repository แบบ private ต้องใช้บัญชี GitHub แบบเสียเงิน
> ถ้าไม่สะดวก สามารถนำโฟลเดอร์ `public/` (หลัง `npm install`) ไปวางบนเว็บโฮสติ้งใดก็ได้ที่เป็น HTTPS

## วิธีใช้งาน

1. แท็บ **สแกน** → เลือก **ถ่ายรูป** หรือ **วิดีโอ**
   - ถ่ายรูป: วางเอกสารในกรอบ ถือให้นิ่ง กดปุ่มกลม — ถ่ายหน้าต่อไปได้เลย ระบบอ่านข้อความเบื้องหลัง
   - วิดีโอ: กดปุ่มแดง ค้างกล้องที่แต่ละหน้า ~2 วินาที แล้วพลิกหน้า/เลื่อนไปหน้าถัดไป กดอีกครั้งเพื่อหยุด
2. แท็บ **เอกสาร** → แตะแต่ละหน้าเพื่อตรวจ/แก้ข้อความ หมุน หรือครอป
3. ตั้งชื่อเอกสาร → กด **บันทึกเป็นไฟล์ Word (.docx)**

## เครื่องมือ OCR

ทั้งสองตัวทำงาน **ในเครื่อง** ไม่ส่งภาพออกไปไหน เลือกได้ที่ ตั้งค่า → เครื่องมืออ่านข้อความ

| | OpenThai2.0-OCR-Text (iApp) — ค่าเริ่มต้น | Tesseract — ตัวสำรอง |
|---|---|---|
| วิธีทำงาน | โมเดล PP-OCR (หาบรรทัด + อ่านบรรทัด) ที่ iApp ฝึกเพิ่มสำหรับภาษาไทย | Tesseract LSTM + ข้อมูลภาษา tha/eng |
| ขนาดดาวน์โหลดครั้งแรก | ~15 MB (onnxruntime-web 11 MB + โมเดล 4 MB) | ~9 MB |
| เบราว์เซอร์ที่ต้องใช้ | WebAssembly SIMD: Chrome/Edge 91+, Safari/iOS 16.4+ | เบราว์เซอร์รุ่นเก่ากว่าได้ |
| ภาพหมุน/ตะแคง | ตรวจและหมุนให้อัตโนมัติ | ต้องหมุนเอง |

ผลทดสอบของเราเอง (ภาพเอกสารสังเคราะห์ 4 ภาพ — ตัวอย่างน้อย ใช้ดูแนวโน้มเท่านั้น; CER = สัดส่วนตัวอักษรที่อ่านผิด ยิ่งต่ำยิ่งดี):

| ภาพทดสอบ | OpenThai | Tesseract |
|---|---|---|
| ใบเสร็จ ภาพคมชัด | CER 0.0% (8/8 บรรทัด) | CER 0.0% (8/8) |
| สัญญาเช่า ภาพคมชัด | CER 0.0% (6/6) | CER 0.0% (6/6) |
| ใบเสร็จ มีเงา เอียง เบลอ | CER 0.0% (8/8) | CER 1.0% (7/8) |
| ใบเสร็จ ตัวเล็ก + เปอร์สเปกทีฟ + JPEG คุณภาพต่ำ | CER 1.5% (6/8) | CER 3.9% (5/8) |

### เคล็ดลับให้อ่านแม่นขึ้น

- แสงสว่างพอ ไม่มีเงามือบังเอกสาร (เปิดไฟแฟลช ⚡ ได้ ถ้ากล้องรองรับ)
- ถือกล้องขนานกับกระดาษ ให้เอกสารเต็มกรอบ ตัวอักษรต้องคมชัด
- ครอปให้เหลือเฉพาะส่วนที่ต้องการ จะอ่านได้แม่นและเร็วขึ้น
- ถ้าหน้าไหนอ่านผิดเยอะ ลองเปลี่ยนเครื่องมืออ่านข้อความในตั้งค่า แล้วกด **อ่านใหม่** ในหน้านั้น
- (Tesseract) ใบเสร็จ/ย่อหน้าเดียว: ตั้งค่า → ลักษณะเอกสาร → **ข้อความก้อนเดียว**
- (Tesseract) ตัวอักษรจางมาก เช่น ใบเสร็จกระดาษความร้อนที่ซีด: ตั้งค่า → ปรับภาพก่อนอ่าน → **ขาว-ดำ**
- **ตรวจตัวเลขทุกครั้งก่อนนำไปใช้** โดยเฉพาะจำนวนเงิน เลขผู้เสียภาษี และวันที่ — OCR อาจอ่าน 0/8, 1/7, 5/6 สลับกันได้
  ช่อง “ความมั่นใจ” ที่ต่ำกว่า 70% (สีเหลือง) ควรตรวจละเอียดเป็นพิเศษ

## โหมดหนังสือ

เปิดได้ที่แท็บ **เอกสาร** (ช่อง “โหมดหนังสือ”) หรือ **ตั้งค่า → หนังสือ** — เปิด/ปิดแล้วจัดข้อความทุกหน้าใหม่ทันที ไม่ต้องสแกนใหม่

| | ทั่วไป | โหมดหนังสือ |
|---|---|---|
| การขึ้นบรรทัด | ตามบรรทัดในภาพ | รวมเป็นย่อหน้า (ภาษาไทยต่อกันโดยไม่เติมช่องว่าง, คำอังกฤษที่ตัดด้วย `-` รวมเป็นคำเดียว) |
| หัวข้อ | ข้อความธรรมดา | ตัวอักษรใหญ่กว่าเนื้อหา → `# หัวข้อ` / `## หัวข้อย่อย` → Heading ใน Word (ใช้กับ Navigation Pane ได้) |
| เลขหน้า, หัวกระดาษ | อยู่ในข้อความ | ตัดออก (เลขหน้า และหัว/ท้ายกระดาษที่ซ้ำกันในหลายหน้า) |
| ภาพหนังสือกาง 2 หน้า | 1 หน้า (กด “แบ่งหน้า” เองได้) | แบ่งซ้าย/ขวาอัตโนมัติเมื่อภาพเป็นแนวนอน |
| ไฟล์ Word | หัวข้อ/ภาพ/ขึ้นหน้าใหม่ทุกหน้า | ข้อความต่อเนื่อง ย่อหน้าเข้า 1 ซม. ย่อหน้าที่ข้ามหน้าถูกรวมเป็นย่อหน้าเดียว |

ในหน้าแก้ไข 1 บรรทัด = 1 ย่อหน้า และบรรทัดที่ขึ้นต้นด้วย `#` คือหัวข้อ — แก้/เพิ่มเองได้

หัวข้อตัวหนาขนาดใหญ่บางแบบ OpenThai อ่านไม่มั่นใจจนตัดทิ้ง แอปจะให้ Tesseract อ่านซ้ำเฉพาะบรรทัดนั้นให้อัตโนมัติ

## PDF เหมือนต้นฉบับ (ค้นหาข้อความได้)

ปุ่ม **PDF เหมือนต้นฉบับ** ในแท็บเอกสาร: แต่ละหน้าเป็นภาพที่สแกนจริง (หน้าตาเหมือนต้นฉบับ 100%)
และมีข้อความที่ OCR อ่านได้ซ่อนอยู่ใต้ภาพตรงตำแหน่งบรรทัด → ค้นหา (Ctrl+F) ไฮไลต์ และคัดลอกข้อความภาษาไทยได้

- ใช้ฟอนต์ Sarabun (SIL OFL) ฝังเฉพาะตัวอักษรที่ใช้ ไฟล์เล็ก
- หน้าที่แก้ข้อความเอง: ตำแหน่งบรรทัดเดิมใช้ไม่ได้ จะเรียงข้อความที่แก้แล้วไว้ใต้ภาพแทน (ยังค้นหาได้)
- เหมาะกับการเก็บเอกสารเป็นหลักฐาน — ถ้าต้องการแก้ไขเนื้อหาต่อ ให้ใช้ไฟล์ Word

### ฟอนต์ในไฟล์ Word

ค่าเริ่มต้นคือ **TH Sarabun New** (ฟอนต์มาตรฐานหนังสือราชการ) — ถ้าเครื่องที่เปิดไฟล์ไม่มีฟอนต์นี้
Word จะแสดงด้วยฟอนต์อื่นแทน เลือกเปลี่ยนเป็น **Angsana New / Cordia New / Tahoma** (มีในทุก Windows)
ได้ที่แท็บ เอกสาร → ตัวเลือกไฟล์ Word

## รันในเครื่อง (สำหรับนักพัฒนา)

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install      # ติดตั้งไลบรารี และคัดลอกไปไว้ที่ public/vendor อัตโนมัติ
npm start        # เปิด http://localhost:8080
npm test         # unit test ของตัวแก้ข้อความไทย
npm run test:e2e # ทดสอบทั้งระบบด้วย Chromium + กล้องจำลอง (ต้องมี Playwright, ffmpeg, unzip, pdftotext)
```

บนคอมพิวเตอร์ `http://localhost` ใช้กล้องได้ แต่ถ้าเปิดจากมือถือผ่าน IP ในวง LAN (http)
เบราว์เซอร์จะไม่อนุญาตให้ใช้กล้อง — ให้ใช้ GitHub Pages หรือเว็บที่เป็น HTTPS

  js/ocr.js             Tesseract.js (ไทย + อังกฤษ) — ตัวสำรอง

## ข้อจำกัด

- OCR อ่านตัวพิมพ์ได้ดี แต่ **ลายมือเขียน** อ่านได้ไม่ดี
- ตารางที่ซับซ้อนจะได้ข้อความเรียงเป็นบรรทัด ไม่ได้เป็นตารางใน Word
- Word ไม่เก็บฟอนต์/ตัวหนา/ตัวเอียง/การจัดกึ่งกลางของต้นฉบับ — ถ้าต้องการหน้าตาเหมือนเดิมให้ใช้ PDF
- โหมดหนังสือเดาหัวข้อและย่อหน้าจากขนาดและตำแหน่งตัวอักษร อาจพลาดได้กับหนังสือที่จัดหน้าแปลก ๆ — ตรวจและแก้ `#` ในหน้าแก้ไขได้
- หน้าหนังสือที่โค้งมากใกล้สันจะอ่านพลาดง่าย ควรกดหนังสือให้แบนก่อนถ่าย
- ครั้งแรกต้องดาวน์โหลดเครื่องมือ OCR (~15 MB สำหรับ OpenThai, Tesseract อีก ~9 MB เมื่อถูกใช้) หลังจากนั้นเก็บไว้ในเครื่อง
- iPhone: ถ่ายภาพได้ความละเอียดเท่าวิดีโอ (Full HD) — ถ้าต้องการคมกว่านั้น
  ใช้ปุ่ม “นำเข้ารูป” แล้วถ่ายด้วยแอปกล้องของเครื่อง
